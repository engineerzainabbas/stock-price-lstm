# 📈 Stock Price Prediction Dashboard

An interactive stock price prediction app built with **Streamlit** and **LSTM Deep Learning**.

## 🚀 Features

- Real-time stock data via `yfinance`
- LSTM model trained on-the-fly in the browser
- Configurable sequence length, epochs, batch size
- Future price forecasting with confidence bands
- Multi-stock performance comparison
- Dark-themed responsive dashboard

## 🛠️ Tech Stack

- **Streamlit** — Web UI
- **TensorFlow / Keras** — LSTM model
- **yfinance** — Real-time & historical stock data
- **scikit-learn** — Data preprocessing & metrics
- **Matplotlib** — Charts

## ▶️ Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/stock-price-lstm.git
cd stock-price-lstm
pip install -r requirements.txt
streamlit run stock_dashboard.py
```

## 🌐 Deploy on Streamlit Cloud

1. Push this repo to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub account
4. Select this repo → set **Main file**: `stock_dashboard.py`
5. Click **Deploy**
